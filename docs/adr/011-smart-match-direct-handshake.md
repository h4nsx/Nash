# ADR-011: Smart Match + Direct Handshake

**Status:** Accepted

**Decision:** Core workflow is `Project → Match → Top 3 → Invitation → Contract Draft → Accept/Counter → Contract`. The open proposal/cover-letter workflow is not an MVP core flow.

**Reason:** Aligns product around verified capabilities, lower-signal application reduction and structured deal closing.

**Consequence:** Match, Invitation and ContractDraft become first-class domains.
