# Roadmap

0. Foundation: repo, Next.js, .NET, Clean Architecture, PostgreSQL, Docker, CI, docs.
1. Identity: registration, JWT, roles, profiles, authorization.
2. Skills: catalog, tests, attempts, verification, versioning.
3. Projects: CRUD, requirements, budget/date, publish/close.
4. Smart Match: eligibility, scoring, reasons, versioning, Top 3, snapshots, refresh.
5. Direct Handshake: invitations, contract drafts, versioning, accept/decline/counter, expiry, concurrency, activation.
6. Work: milestones, delivery, changes, completion, reviews, notifications.
7. CMS/SEO: pages, articles, media, metadata, sitemap, moderation.
8. Hardening: Redis, Hangfire, SignalR, telemetry, Sentry, rate limiting, security/backup review.
9. Launch: staging, production, Cloudflare, monitoring, runbooks, demo environment.

Future only when justified: advanced matching, payments/escrow, messaging expansion, service extraction/search infrastructure.
